# Complete supplied-paper and erratum reading notes

The reviewer read supplied arXiv v2 PDF pages 1–39 in order, including the appendix and reference material, and the entire one-page erratum. Critical expressions were compared with author TeX and selected actual VOR page pixels. The current journal text is an authoritative comparison edition; the institution's cover alone does not establish article-version identity.

Pages 1–5 establish the cold-ion, weakly driven, unmagnetized 2D2V Vlasov–Poisson problem. The simulations begin with no relative drift rather than supercritical initial conditions. Table 1 distinguishes mass ratio, drive and temperature-ratio cases. The study explicitly discloses limited linear resolution for the mass-200 run. No claim of absent input files is justified: page 24 links the actual deposited decks.

Pages 6–10 describe freely accelerated linear growth, quasi-linear saturation, and a fitted electron bulk/tail model. The text distinguishes wave energy from the signed mode amplitude. Table 2 provides positive approximate agreement of peak energy with the quasi-linear scaling. The distribution fit is explicitly a model and the parallel-only marginality test is acknowledged as not fully rigorous in a 2D system. The growth integration and thermal/dispersion conventions deserve focused checks, rather than rejection of these numerical observations.

Pages 11–16 discuss ion heating, trapping, shifted spectra, oblique modes, KP-like spectra, double layers and EAWs. Frequency–wavenumber spectra in Figures 5 and 7 use run M25E10 because the main run lacks sufficiently frequent output; those figures must not be mislabeled as Main diagnostics. The interpretation links evidence from several diagnostics but makes no complete energy-transfer-budget measurement. The late double-layer scale is acknowledged elsewhere to be constrained by the periodic box.

Pages 17–23 define effective anomalous collision frequency from current acceleration and compare it with quasi-linear estimates. The paper separates weak and extremely weak drive, uses second-moment temperature even for non-Maxwellian distributions, and admits that temperature alone does not determine exact stability. The fitted heating and duration estimates are approximate and explicitly exclude the extremely weak branch where the heating fit fails. The late-time/asymptotic state was not reached, and the conclusion admits this limitation. Box-size restrictions and limited long-wavelength content are also disclosed. The neighboring reconnection-field normalizations merit algebraic reconciliation without treating the astrophysical scenario as numerically refuted.

Pages 24–30 contain the data statement and Appendices A–E: linear response, a positive 1D/2D contrast, actual double-Maxwellian fitting parameters, the principal-value EAW approximation and the extremely weak-drive threshold. The threshold is approximate and tied to an assumed noise level. A correction to a time-dependent exponential must not be propagated into (E11) by guesswork; the remaining algebra should be rederived independently. Normal-Gaussian and Fried–Conte definitions of the plasma dispersion function can legitimately differ, so the zeta issue requires an explicit convention.

Pages 30–34 provide ideal-resolution estimates and actual linear/nonlinear resolution tests. These are substantive positive numerical controls, not absent convergence discussion. The Main deck uses polynomial order two; approximate division of cell spacing by p+1 reproduces the reported effective position/velocity spacings. Treating cell count alone as the paper's effective grid would manufacture a discrepancy. Pages 34–39 contain the complete bibliography, which was read; no claim that each cited third-party paper was also fully read is implied.

The one-page published erratum corrects only an editor acknowledgement. It provides no basis for claiming that numerical or analytical errors were already acknowledged by the source authors. Conversely, its existing correction cannot be republished as an original finding. The current VOR already incorporates that acknowledgement change.
